📦 3. Instalación de BIND9

Instalaremos el servicio DNS y comprobaremos que se encuentra correctamente disponible en nuestro servidor.

🎯 Objetivo

Instalar BIND9 y sus herramientas de administración en el servidor DNS-LDAP, comprobar la configuración del firewall y verificar que el servicio DNS se encuentra activo.

3.1. Actualizar los repositorios

Antes de instalar un nuevo paquete, actualiza la información disponible sobre los paquetes y versiones de los repositorios configurados en Ubuntu Server.

sudo apt update
💡 ¿Qué estamos haciendo?

Este comando actualiza el índice local de paquetes. No instala BIND9 todavía.

3.2. Instalar BIND9

Instalaremos el servidor DNS BIND9 junto con el paquete bind9-utils, que incorpora herramientas que utilizaremos posteriormente para trabajar y realizar comprobaciones sobre el servicio.

sudo apt install bind9 bind9-utils

Confirma la instalación cuando el sistema lo solicite y espera hasta que finalice el proceso.

📦 ¿Qué estamos instalando?

bind9 proporciona el servicio DNS que se ejecutará en nuestro servidor.

bind9-utils proporciona herramientas auxiliares para administrar y comprobar la configuración de BIND9.

3.3. Comprobar el firewall

Antes de continuar, comprueba si el firewall UFW está activo en el servidor.

sudo ufw status

Observa el resultado obtenido.

🔐 Si UFW está activo

Debemos permitir el tráfico correspondiente al servicio BIND9.

sudo ufw allow bind9

ℹ️ Si UFW está inactivo

No es necesario añadir esta regla en este momento. Continúa con la comprobación del servicio.

3.4. Comprobar el servicio BIND9

Una vez finalizada la instalación, comprueba el estado del servicio:

sudo systemctl status bind9

Examina la información mostrada por systemctl y localiza el estado del servicio.

✅ ¿Qué deberías encontrar?

Si la instalación se ha realizado correctamente, el servicio BIND9 deberá aparecer como activo.

📌 Recuerda

Que BIND9 esté activo significa que el servicio se está ejecutando. Todavía no hemos realizado la configuración necesaria para nuestra Red Interna.

✅ Comprobación de la instalación

Antes de continuar, verifica que puedes responder afirmativamente a las siguientes comprobaciones:

☐ Los repositorios se han actualizado correctamente.

☐ bind9 y bind9-utils están instalados.

☐ Se ha comprobado el estado de UFW.

☐ Si UFW está activo, se ha permitido el tráfico de BIND9.

☐ systemctl status bind9 muestra que el servicio está activo.

📁 Portfolio

Documenta la instalación realizada y conserva una evidencia que permita comprobar que BIND9 está instalado y el servicio se encuentra activo.

➡️ Siguiente paso

BIND9 ya está instalado y en ejecución. Ahora debemos configurarlo para que atienda las consultas de nuestra Red Interna y pueda resolver nombres externos.
