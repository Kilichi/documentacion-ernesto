🧰 1.4 · What do we need?

¿Qué necesitamos recordar antes de construir nuestro entorno?

🎯 Objetivo
Identificar los conocimientos y procedimientos que necesitamos recuperar para configurar, administrar y comprobar nuestro entorno de despliegue.

Ya conocemos nuestro escenario. Sabemos qué máquinas lo forman, cómo estarán conectadas y qué recorrido puede seguir una comunicación.

El siguiente paso será construirlo. Pero antes de comenzar necesitamos asegurarnos de que disponemos de las herramientas y conocimientos necesarios para hacerlo.

🤔 Antes de empezar...

¿Qué necesitamos saber hacer para convertir este diseño en una infraestructura funcional?

🔍 Observemos nuestro escenario

Cada elemento que hemos estudiado nos plantea una necesidad. Vamos a identificarlas antes de continuar.

🐧 Administrar sistemas Linux

Nuestros servidores utilizan Ubuntu Server y también trabajaremos con un cliente Linux Mint. Necesitaremos manejarnos con seguridad dentro de estos sistemas.

Necesitaremos recordar cómo...
  • Trabajar con usuarios y grupos.
  • Movernos por el sistema de archivos.
  • Crear y gestionar directorios y ficheros.
  • Interpretar y modificar permisos.
  • Utilizar privilegios administrativos cuando sea necesario.
⌨️ Trabajar desde la terminal

Ubuntu Server se administrará principalmente desde la línea de comandos. Por tanto, necesitaremos recuperar soltura trabajando desde una terminal.

Necesitaremos recordar cómo...
  • Ejecutar comandos y utilizar sus opciones.
  • Consultar información del sistema.
  • Editar ficheros de configuración.
  • Trabajar con rutas absolutas y relativas.
  • Interpretar la información que devuelve un comando.
🌐 Configurar una red

Nuestras máquinas pertenecerán a la red 192.168.X.0/24. Para configurarlas correctamente necesitaremos interpretar y utilizar los principales parámetros de una configuración IPv4.

Necesitaremos recordar cómo...
  • Interpretar una dirección IPv4.
  • Comprender qué indica una máscara o prefijo de red.
  • Identificar si dos direcciones pertenecen a la misma red.
  • Identificar y configurar interfaces de red.
  • Comprender la función de una puerta de enlace.
🩺 Comprobar y diagnosticar

Configurar una máquina no significa que hayamos terminado. Después tendremos que comprobar que la configuración funciona y localizar el problema cuando algo falle.

Necesitaremos recordar cómo...
  • Consultar la configuración de las interfaces.
  • Comprobar la conectividad entre dos equipos.
  • Interpretar los resultados de una prueba.
  • Distinguir entre un problema de configuración y uno de conectividad.
  • Seguir un procedimiento básico de diagnóstico.

🧩 Todo está relacionado

Estos conocimientos no aparecen de forma aislada. Los necesitaremos para resolver situaciones concretas dentro de nuestro entorno.

En nuestro escenario... Necesitaremos...
Administrar Ubuntu Server Usuarios, grupos, permisos, directorios y privilegios
Configurar 192.168.X.0/24 IPv4, prefijos, interfaces y puerta de enlace
Administrar los servidores Trabajar con seguridad desde la terminal
Saber si dos máquinas pueden comunicarse Comprobar la conectividad e interpretar los resultados
Algo no funciona como esperábamos Diagnosticar el problema de forma ordenada
💭 ¿Lo recuerdas?

Muchos de estos conocimientos ya los has trabajado anteriormente. Antes de utilizarlos en nuestro nuevo entorno, vamos a recuperarlos y ponerlos de nuevo en práctica.

No se trata de aprender todavía a desplegar nuestros servicios, sino de asegurarnos de que contamos con una base técnica común para poder hacerlo.

Ya sabemos qué vamos a necesitar.
