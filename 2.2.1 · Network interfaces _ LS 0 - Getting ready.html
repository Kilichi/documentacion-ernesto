2.2.1 · Network interfaces

🔌 2.2.1 · Network interfaces

Recuperamos cómo identificar y comprobar las interfaces de red en Linux

🎯 Objetivo
Recordar qué es una interfaz de red, identificar las interfaces disponibles en un sistema Linux y utilizar las herramientas básicas para consultar e interpretar su estado y configuración actual.

Antes de asignar una dirección IP a una máquina necesitamos saber qué interfaces de red tiene disponibles.

Una interfaz de red es el punto mediante el que un sistema puede conectarse a una red. En nuestras máquinas virtuales, estas interfaces están asociadas a los adaptadores de red que hemos configurado previamente en VirtualBox.

🔗 VirtualBox ↔ Linux

Cuando añadimos o habilitamos un adaptador de red en VirtualBox, el sistema operativo invitado puede detectarlo como una interfaz de red.

En nuestro escenario encontraremos nombres como enp0s3 y enp0s8.

💡 Recuerda

El nombre de una interfaz como enp0s3 no significa que sea una interfaz de Internet, NAT o Red interna. Su función depende de cómo esté conectado el adaptador correspondiente en VirtualBox.

🔌 1 · Identifying network interfaces

Linux asigna un nombre a cada interfaz de red. En nuestros servidores podremos encontrar nombres como:

enp0s3

Primera interfaz Ethernet de nuestras máquinas virtuales.

enp0s8

Segunda interfaz Ethernet presente en DNS-LDAP.

lo

Interfaz de loopback utilizada para comunicaciones internas del propio sistema.

🔄 2 · The loopback interface

Además de las interfaces asociadas a los adaptadores de red, encontraremos normalmente una interfaz denominada lo.

Se trata de la interfaz de loopback. Permite que una máquina se comunique consigo misma y suele estar asociada a la dirección:

127.0.0.1
💡 Importante

lo no corresponde a ningún adaptador de red que tengamos que añadir en VirtualBox.

👀 3 · Checking our interfaces

Podemos consultar las interfaces disponibles y su estado mediante:

$ ip link

Una salida simplificada podría mostrar:

1: lo: <LOOPBACK,UP,LOWER_UP> ...
2: enp0s3: <BROADCAST,MULTICAST,UP,LOWER_UP> ...
   link/ether 08:00:27:ab:cd:ef ...

No necesitamos memorizar toda la salida. Lo importante es aprender a localizar la información que necesitamos.

Información ¿Qué nos indica?
enp0s3 Nombre de la interfaz.
UP La interfaz está habilitada administrativamente.
LOWER_UP La capa inferior de la interfaz dispone de enlace.
link/ether Muestra la dirección MAC de la interfaz Ethernet.

🏷️ 4 · MAC address

Una interfaz Ethernet dispone de una dirección MAC que permite identificarla en la comunicación a nivel de enlace.

En la salida de ip link podemos localizarla después de:

link/ether 08:00:27:ab:cd:ef

Cada interfaz de una máquina dispone de su propia dirección MAC. Por tanto, una máquina con dos interfaces de red tendrá dos interfaces y dos direcciones MAC diferentes.

🌐 5 · Checking the current configuration

Si además queremos consultar la información relacionada con las direcciones configuradas en las interfaces, podemos utilizar:

$ ip addr

También podemos abreviarlo:

$ ip a

O consultar únicamente una interfaz concreta:

$ ip addr show enp0s3

Una salida simplificada podría contener:

2: enp0s3: <BROADCAST,MULTICAST,UP,LOWER_UP> ...
   link/ether 08:00:27:ab:cd:ef ...
   inet 192.168.200.104/24 ...

Ahora podemos relacionar en una misma salida el nombre de la interfaz, su dirección MAC y la dirección IPv4 configurada.

⏳ Por ahora...

Podemos reconocer que aparece una dirección como 192.168.200.104/24, pero todavía no vamos a analizar qué significa cada parte.

Lo recuperaremos en 2.2.2 · IPv4 addressing.

🖥️ 6 · Interfaces in our deployment environment

Volvamos ahora a nuestras máquinas virtuales.

Máquina Interfaz Conectada a
DNS-LDAP enp0s3 Red NAT / NAT
DNS-LDAP enp0s8 Red interna
Git enp0s3 Red interna
Web enp0s3 Red interna
FTP enp0s3 Red interna
Linux Mint enp0s3 Red interna
🧠 ¿Por qué DNS-LDAP es diferente?

Es la única máquina de nuestro escenario que participa en dos redes diferentes. Por eso necesita dos interfaces:

  • enp0s3 → conectada a la Red NAT /NAT.
  • enp0s8 → conectada a la Red interna.
🔍 Check it

En una de tus máquinas Ubuntu Server ejecuta:

$ ip link
$ ip addr

Localiza:

  • la interfaz lo;
  • la interfaz o interfaces Ethernet;
  • su estado;
  • su dirección MAC;
  • si actualmente tienen alguna dirección IPv4.
🧩 Mini challenge · Identify your network

Ha llegado el momento de comprobar que las interfaces de nuestras máquinas coinciden con el diseño del entorno de despliegue.

Tu tarea:

  1. Inicia las máquinas DNS-LDAP y Web.
  2. Sin modificar todavía su configuración de red, identifica las interfaces disponibles en cada máquina.
  3. Determina cuál corresponde a cada adaptador configurado en VirtualBox.
  4. Localiza la dirección MAC de cada interfaz.
  5. Comprueba el estado de las interfaces.
  6. Explica por qué DNS-LDAP dispone de dos interfaces mientras que Web dispone únicamente de una.
🔍 Antes de terminar

Debes poder identificar cada interfaz y explicar a qué red está conectada y qué función tendrá dentro de nuestro escenario.

🧠 What should you remember?

  • Una máquina puede disponer de una o varias interfaces de red.
  • lo es la interfaz de loopback.
  • ip link permite consultar interfaces y su estado.
  • ip addr permite consultar también las direcciones asociadas a las interfaces.
  • Cada interfaz Ethernet dispone de una dirección MAC.
  • El nombre enp0s3 o enp0s8 no determina por sí mismo a qué red está conectada la interfaz.
