1.1. Meet our servers

🖥️ 1.1 · Meet our servers

Conoce las máquinas de nuestro entorno

🎯 Objetivo
Identificar las máquinas que forman nuestro entorno de despliegue, reconocer el papel que tendrá cada una e interpretar el direccionamiento IP que utilizaremos.

Nuestro entorno está formado por cinco máquinas virtuales: Cuatro servidores con Ubuntu Server y un equipo cliente con Linux Mint.

Los nombres de los servidores indican el papel que desempeñarán más adelante. En este momento todavía no hemos instalado ni configurado los servicios DNS, LDAP, Git, Web o FTP.

💡 Importante
Partimos de una infraestructura básica. A medida que avancemos en el módulo iremos instalando, configurando y comprobando los diferentes servicios.

🌐 Tu rango de red

Todos los equipos del aula trabajarán con la misma estructura de direccionamiento, pero cada alumno dispondrá de su propio rango de red.

Tu red interna
192.168.X.0/24
X = número de rango indicado en el aula

La X corresponde exclusivamente al tercer octeto. Este valor será el mismo en todas las máquinas de tu entorno.

🔎 Ejemplo

Si el rango asignado es X = 200, tu red será:

192.168.200.0/24

Todas tus máquinas utilizarán, por tanto, 200 como tercer octeto.

🖥️ Las máquinas de nuestro entorno

Cada máquina tendrá una función diferente dentro de la infraestructura.

🖥️ DNS-LDAP
Sistema: Ubuntu Server
Red interna: 192.168.X.253/24

Será el servidor encargado posteriormente de los servicios DNS y LDAP. Además, será la única máquina conectada tanto a nuestra red interna como a la Red NAT.

🗃️ Git
Sistema: Ubuntu Server
Dirección: 192.168.X.104/24

Más adelante lo utilizaremos para alojar los servicios relacionados con el control de versiones.

🌐 Web
Sistema: Ubuntu Server
Dirección: 192.168.X.154/24

Será la máquina destinada posteriormente al despliegue de servicios web.

📁 FTP
Sistema: Ubuntu Server
Dirección: 192.168.X.204/24

Será el servidor destinado posteriormente a los servicios de transferencia de archivos.

💻 Linux Mint
Sistema: Linux Mint
Dirección: 192.168.X.Y/24

Esta máquina no es un servidor. Será nuestro equipo cliente y la utilizaremos para acceder, administrar y comprobar los servicios que vayamos desplegando.

🔢 ¿Qué significan X e Y?

X · Tu rango

Es el tercer octeto y será indicado en el aula. Se mantiene igual en todas las máquinas de tu entorno.

Y · Tu elección

Es el cuarto octeto de Linux Mint. Elegirás un valor válido que no esté siendo utilizado por otra máquina de tu red.

🧩 Construyamos un ejemplo

Supongamos que tienes asignado el rango X = 200 y eliges Y = 200 para Linux Mint:

Máquina Dirección IP Tipo
DNS-LDAP 192.168.200.253 Servidor
Git 192.168.200.104 Servidor
Web 192.168.200.154 Servidor
FTP 192.168.200.204 Servidor
Linux Mint 192.168.200.200 Cliente
