🏗️ 3 · Setting up our deployment environment

Build your deployment infrastructure

🎯 Objetivo

Construir y configurar de forma autónoma el entorno de despliegue diseñado al inicio de esta situación de aprendizaje, seleccionando y aplicando los procedimientos necesarios para cumplir las especificaciones establecidas.

🧠 From guided practice to autonomous work

En 1 · Our deployment environment analizaste la infraestructura que necesitamos y comprendiste cómo deben relacionarse sus máquinas.

En 2 · Refreshing our skills recuperaste las herramientas de Linux, direccionamiento, configuración y diagnóstico necesarias para trabajar con ella.

Ahora debes utilizar esos conocimientos de forma autónoma. No encontrarás una secuencia de pasos ni los comandos que debes ejecutar.

🏗️ The challenge

A partir de las máquinas virtuales proporcionadas, construye y configura el entorno de despliegue definido en el apartado 1.

Tú decides cómo organizar el trabajo, qué procedimientos necesitas, en qué orden realizarlos y qué herramientas utilizar.

📋 Technical specifications

Tu entorno debe respetar las siguientes especificaciones. Estas indican qué debes conseguir, no cómo conseguirlo.

Machine Internal IPv4 Network connection
DNS-LDAP 192.168.X.253/24 Red NAT / NAT + Red interna
Git 192.168.X.104/24 Red interna
Web 192.168.X.154/24 Red interna
FTP 192.168.X.204/24 Red interna
Linux Mint 192.168.X.Y/24 Red interna
🌐 Remember your range

X Corresponde exclusivamente al tercer octeto y será el número de rango que tienes asignado en el aula.

Para Linux Mint, selecciona un valor Y válido que no genere ningún conflicto de direccionamiento.

⚙️ Requirements

  • Las cinco máquinas deben reproducir la arquitectura definida.
  • DNS-LDAP debe ser la única máquina conectada simultáneamente a la Red NAT y a la Red interna.
  • Las máquinas de la Red interna deben utilizar direccionamiento IPv4 estático.
  • Git, Web y FTP utilizarán 192.168.X.253 como puerta de enlace.
  • No deben existir conflictos de direccionamiento.
  • Todavía no debes instalar ni configurar los servicios DNS, LDAP, Git, Web o FTP.
🧭 You choose the path

No se proporciona un procedimiento de resolución. Si necesitas recuperar un concepto, un comando o un procedimiento, vuelve a consultar 2 · Refreshing our skills.

Antes de modificar algo, piensa qué necesitas conseguir y qué información necesitas conocer.

✅ Definition of Done

Consideraremos finalizada la construcción cuando:

  • Las cinco máquinas están preparadas.
  • Sus adaptadores están asociados a las redes correspondientes.
  • Cada máquina tiene asignado el direccionamiento previsto.
  • Las rutas necesarias están configuradas conforme al diseño.
  • No existen conflictos de direccionamiento.
🏗️ Environment built. But does it work?

Haber construido y configurado el entorno no es suficiente. Ahora tendrás que demostrar que funciona.
