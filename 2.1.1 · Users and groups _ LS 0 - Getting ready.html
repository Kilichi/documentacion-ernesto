👥 2.1.1 · Users and groups

Recuperamos la gestión de usuarios y grupos en Linux

🎯 Objetivo
Recordar cómo Linux identifica y organiza a sus usuarios y grupos, interpretar la información básica asociada a ellos y recuperar los comandos necesarios para crearlos, modificarlos y comprobar su configuración.

En Linux, cada usuario dispone de una identidad propia dentro del sistema. Esta identidad permite diferenciar quién está trabajando, qué recursos utiliza y, como veremos posteriormente, qué acciones puede realizar sobre ellos.

Los grupos permiten organizar varios usuarios bajo una misma identidad colectiva. Más adelante podremos utilizar esta organización para controlar el acceso a ficheros, directorios y otros recursos del sistema.

🔎 ¿Por qué necesitamos recordarlo?

Cuando administremos nuestros servidores DNS-LDAP, Git, Web o FTP tendremos que trabajar con diferentes usuarios y grupos. Además, algunos de los servicios que instalaremos podrán disponer de sus propios usuarios del sistema.

Antes de llegar a ese punto necesitamos recordar cómo identifica Linux a cada usuario y cómo podemos organizarlos mediante grupos.

👤 1 · Users

Un usuario representa una identidad dentro del sistema Linux. Cada usuario dispone de un identificador numérico denominado UID (User Identifier).

No todos los usuarios tienen que representar necesariamente a una persona. Linux también puede utilizar cuentas asociadas a servicios y procesos para limitar los recursos a los que estos pueden acceder.

💡 Idea principal

En Linux, el nombre de usuario nos resulta cómodo a las personas, pero internamente la identidad del usuario está asociada a su UID.

El usuario root, por ejemplo, tiene UID 0.

🔎 Who am I?

Antes de administrar otros usuarios, podemos comenzar identificando nuestra propia cuenta.

$ whoami
$ id
$ groups
Comando ¿Qué nos permite comprobar?
whoami El usuario con el que estamos trabajando.
id UID, grupo principal y grupos a los que pertenece el usuario.
groups Los grupos a los que pertenece el usuario.
🔍 Check it

Ejecuta los tres comandos en tu sistema. ¿Puedes identificar tu nombre de usuario, tu UID, tu GID y los grupos a los que perteneces?

📄 2 · Where are users stored?

Linux mantiene información sobre las cuentas de usuario en el fichero:

/etc/passwd

Cada línea representa una cuenta y contiene diferentes campos separados mediante :.

usuario:x:1000:1000:usuario:/home/usuario:/bin/bash
Campo Significado
Login Nombre utilizado para identificar al usuario.
Password Normalmente aparece x; la información de contraseña se gestiona mediante /etc/shadow.
UID Identificador numérico del usuario.
GID Identificador de su grupo principal.
GECOS Información adicional sobre el usuario.
Home Directorio personal del usuario.
Shell Shell utilizada por defecto al iniciar una sesión.

🔐 3 · What about passwords?

Las contraseñas no se almacenan directamente en /etc/passwd. Linux utiliza otro fichero:

/etc/shadow

Este fichero contiene información relacionada con las contraseñas y su caducidad. El valor de la contraseña se almacena mediante un hash, no como una contraseña legible.

🔒 Importante

No debemos editar manualmente /etc/passwd o /etc/shadow para crear o modificar usuarios. Linux dispone de comandos específicos para realizar estas operaciones de forma controlada.

⌨️ 4 · Managing users

Podemos crear, modificar y eliminar cuentas utilizando herramientas específicas del sistema.

Comando Función
adduser Crea una nueva cuenta de usuario de forma interactiva.
useradd Crea una nueva cuenta utilizando las opciones indicadas.
usermod Modifica una cuenta existente.
passwd Establece o modifica la contraseña de un usuario.
userdel / deluser Elimina una cuenta de usuario.
📖 No memorices todas las opciones

Utiliza man, -h o --help cuando necesites consultar las opciones disponibles.

$ man usermod
$ usermod --help

👥 5 · Groups

Los grupos permiten organizar usuarios para poder gestionar conjuntamente su acceso a determinados recursos.

Un usuario dispone de un grupo primario y puede pertenecer además a diferentes grupos suplementarios.

👤 Grupo primario

Es el grupo identificado mediante el GID principal asociado al usuario.

👥 Grupos suplementarios

Son otros grupos a los que puede pertenecer el usuario además de su grupo principal.

📄 6 · Where are groups stored?

La información sobre los grupos del sistema se encuentra principalmente en:

/etc/group

Cada línea contiene el nombre del grupo, información relacionada con su contraseña, su GID y la lista de usuarios que aparecen como miembros.

developers:x:1002:ana,pablo

⌨️ 7 · Managing groups

Comando Función
groupadd Crea un grupo.
groupmod Modifica un grupo.
groupdel Elimina un grupo.

🔗 8 · Adding users to groups

El comando usermod también nos permite modificar los grupos a los que pertenece un usuario.

Cambiar el grupo primario:

$ usermod -g GROUP USER

Establecer los grupos suplementarios:

$ usermod -G GROUPS USER

Añadir un nuevo grupo suplementario:

$ usermod -aG GROUP USER
⚠️ Atención con -G

La opción -G establece la lista de grupos suplementarios. Si queremos añadir un grupo conservando los grupos suplementarios que el usuario ya tenía, debemos utilizar también -a (append).

🧪 9 · Let's interpret a command

Observa el siguiente comando:

$ usermod -aG sudo admin_temp
Elemento Significado
usermod Modifica una cuenta de usuario existente.
-a Añade la nueva pertenencia sin eliminar las anteriores.
-G sudo Indica que sudo será un grupo suplementario.
admin_temp Es el usuario que estamos modificando.
🔍 Check it

Después de realizar una modificación, no debemos asumir que todo está correcto. Comprobamos el resultado.

$ id admin_temp
$ groups admin_temp
🧩 Mini challenge · Prepare a technical user

Necesitamos preparar una cuenta temporal para realizar tareas de administración en uno de nuestros servidores.

Tu objetivo:

  1. Crea un usuario llamado admin_temp.
  2. Establece una contraseña para el usuario.
  3. Comprueba su UID, GID y grupos.
  4. Añade admin_temp al grupo sudo.
  5. Comprueba que conserva sus pertenencias anteriores.
🔍 Antes de terminar

No basta con ejecutar los comandos. Demuestra que el resultado es el esperado.
