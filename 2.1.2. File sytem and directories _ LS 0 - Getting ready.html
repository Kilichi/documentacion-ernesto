2.1.2. File sytem and directories

📁 2.1.2 · File system and directories

Recuperamos cómo se organiza y cómo nos movemos por un sistema Linux

🎯 Objetivo
Recordar cómo se organiza el sistema de archivos de Linux, interpretar rutas absolutas y relativas y recuperar los comandos necesarios para desplazarnos y trabajar con archivos y directorios.

Ya hemos recuperado cómo Linux identifica a sus usuarios y grupos. Ahora necesitamos recordar dónde se encuentran y cómo se organizan los recursos con los que estos usuarios trabajan.

En nuestros servidores tendremos que localizar archivos de configuración, movernos entre directorios, crear estructuras de trabajo y manipular archivos desde la terminal. Para hacerlo correctamente necesitamos comprender primero cómo organiza Linux su sistema de archivos.

🔎 ¿Por qué necesitamos recordarlo?

Cuando trabajemos con nuestros servidores DNS-LDAP, Git, Web y FTP no dispondremos siempre de una interfaz gráfica. Tendremos que saber dónde estamos, dónde se encuentra un recurso y cómo llegar hasta él utilizando la terminal.

🌳 1 · The Linux file system

Linux organiza sus archivos y directorios mediante una estructura jerárquica. Todo parte de un único punto, denominado directorio raíz, representado mediante:

/
/
├── etc
├── home
│   └── user
├── root
├── tmp
├── usr
└── var
💡 Concepto básico:

A diferencia de otros sistemas operativos, no encontraremos diferentes árboles identificados mediante letras como C: o D:. En Linux, los recursos se integran dentro de una única estructura que comienza en /.

🗂️ 2 · Some directories you should recognize

No necesitamos memorizar toda la estructura del sistema, pero sí reconocer algunos directorios que encontraremos frecuentemente durante la administración de nuestros servidores.

Directorio ¿Qué encontraremos?
/ Raíz del sistema de archivos.
/home Directorios personales de los usuarios habituales.
/root Directorio personal del usuario root.
/etc Archivos de configuración del sistema y de numerosos servicios.
/var Datos variables generados durante el funcionamiento del sistema y de sus servicios.
/tmp Archivos temporales.
/usr Programas, bibliotecas y otros recursos utilizados por el sistema.

📍 3 · Where am I?

Cuando trabajamos desde la terminal siempre nos encontramos situados en un directorio concreto. Este recibe el nombre de directorio de trabajo actual.

Podemos averiguar dónde estamos utilizando:

$ pwd

Por ejemplo:

$ pwd
/home/student

🧭 4 · Absolute and relative paths

Una ruta indica dónde se encuentra un archivo o directorio dentro del sistema.

📍 Absolute path

Indica la ubicación completa comenzando desde el directorio raíz.

/home/student/project
🧭 Relative path

Indica una ubicación tomando como referencia el directorio en el que estamos.

project/files

🔎 5 · Useful references

Referencia Significado
. Directorio actual.
.. Directorio padre.
~ Directorio personal del usuario actual.
/ Directorio raíz.

🚶 6 · Moving around

Utilizamos cd para cambiar nuestro directorio de trabajo.

$ cd /etc
$ cd /home/student
$ cd ..
$ cd ~
🔍 Check it

Después de utilizar cd, comprueba tu ubicación mediante pwd. No des por supuesto que estás donde esperabas estar.

👀 7 · What's here?

El comando ls nos permite consultar el contenido de un directorio.

$ ls
$ ls -l
$ ls -a
$ ls -lh
Opción Función
-l Muestra información detallada.
-a Incluye los archivos y directorios ocultos.
-h Muestra los tamaños en un formato más fácil de interpretar.
💡 Archivos ocultos

En Linux, un archivo o directorio cuyo nombre comienza por . se considera oculto. Por ejemplo: .bashrc.

📂 8 · Working with directories

Comando Función
mkdir Crear un directorio.
rmdir Eliminar un directorio vacío.
$ mkdir project
$ mkdir project/config
$ rmdir project/config

📄 9 · Working with files

Comando Función
touch Crear un archivo vacío o actualizar su marca temporal.
cp Copiar archivos o directorios.
mv Mover o renombrar archivos y directorios.
rm Eliminar archivos.
$ touch notes.txt
$ cp notes.txt notes_backup.txt
$ mv notes.txt project/
$ rm notes_backup.txt
⚠️ Think before you delete

Los comandos de eliminación pueden modificar el sistema de forma inmediata. Antes de utilizar rm, comprueba dónde estás y qué elemento estás indicando en la ruta.

🧩 Mini challenge · Prepare your workspace

Antes de comenzar a trabajar con nuestros servidores necesitamos recuperar nuestra capacidad para desenvolvernos desde la terminal.

Desde tu directorio personal:

  1. Crea un directorio llamado daw_lab.
  2. Dentro de él, crea los directorios config y backup.
  3. Crea dentro de config un archivo llamado server.conf.
  4. Copia server.conf dentro de backup.
  5. Regresa a tu directorio personal utilizando una única referencia.
  6. Comprueba la estructura que has creado.
🔍 Antes de terminar

Debes poder explicar dónde estabas, qué ruta utilizaste y cómo comprobaste el resultado.
