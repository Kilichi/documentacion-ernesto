1. Introducción

Nuestro entorno de despliegue está formado por varias máquinas virtuales conectadas mediante una Red Interna de VirtualBox. Esta red permite que los equipos se comuniquen entre sí, pero se encuentra aislada del exterior.

Para ampliar nuestra infraestructura vamos a preparar el servidor DNS-LDAP. Este equipo tendrá un papel esencial: proporcionará resolución DNS a los equipos de la red interna y actuará como router para permitir su comunicación con Internet.

🎯 Objetivo

Realizar la instalación y configuración básica de BIND9 y preparar el servidor DNS-LDAP para proporcionar resolución de nombres externos y actuar como puerta de enlace de la red interna.

🧭 Punto de partida

Hasta este momento hemos preparado un entorno virtual en el que nuestros servidores y el equipo cliente pueden comunicarse utilizando sus direcciones IP.

Sin embargo, todavía necesitamos proporcionar a la infraestructura dos capacidades importantes:

1. Resolver nombres de dominio externos mediante un servicio DNS.

2. Permitir que las máquinas conectadas a la Red Interna puedan comunicarse con Internet.

Ambas funciones serán proporcionadas por nuestro servidor DNS-LDAP.

⚙️ Funciones del servidor DNS-LDAP

En esta primera configuración, el servidor DNS-LDAP desempeñará dos funciones diferentes pero complementarias.

🌐

Servidor DNS-LDAP

Instalaremos BIND9 para que el servidor pueda recibir consultas DNS procedentes de los equipos de nuestra red interna.

En esta configuración inicial utilizaremos reenviadores DNS para obtener la resolución de nombres externos.

🔀

Router de la red interna

El servidor estará conectado tanto a la Red Interna de VirtualBox como a una red con acceso al exterior.

De esta forma podrá actuar como puerta de enlace y encaminar hacia Internet el tráfico generado por las máquinas de nuestra red interna.

📌 Alcance de esta configuración

En este recurso realizaremos únicamente la configuración básica del servicio DNS. Instalaremos BIND9, permitiremos las consultas desde nuestra red interna y configuraremos la resolución de nombres externos.

La creación y administración de zonas y registros DNS no se realizará todavía. Estos contenidos se abordarán posteriormente al trabajar de forma específica con el servidor DNS-LDAP.

✅ Resultado esperado

Al finalizar esta configuración, los equipos conectados a nuestra Red Interna deberán poder utilizar el servidor DNS-LDAP como servidor DNS y puerta de enlace.

Como resultado, deberán ser capaces de acceder a Internet y resolver nombres de dominio externos a través de la infraestructura que hemos configurado.
