📋 Your assignment

El entorno debe cumplir los siguientes requisitos:

👤 Requirement 1 · Administration account

Debe existir un usuario llamado daw_temp que utilizaremos como cuenta temporal de administración.

Este usuario debe poder realizar tareas administrativas mediante sudo.

👥 Requirement 2 · Working group

Debe existir un grupo denominado desarrollo.

La cuenta daw_temp debe pertenecer también a este grupo.

📁 Requirement 3 · Workspace

Completa tu espacio de trabajo para que tenga esta estructura:

~/daw_lab/
├── config/
│   └── server.conf
├── backup/
│   └── server.conf
└── shared/
🔐 Requirement 4 · Protect the configuration

El archivo config/server.conf debe estar protegido.

  • El propietario debe poder leerlo y modificarlo.
  • El grupo propietario debe poder leerlo.
  • El resto de usuarios no debe tener ningún permiso.
🤝 Requirement 5 · Shared resources

El directorio shared debe estar asociado al grupo desarrollo.

El propietario y los miembros del grupo deben poder acceder, crear y modificar recursos en él, mientras que el resto de usuarios no debe disponer de permisos.

🧠 Before touching the system

No empieces ejecutando comandos inmediatamente.

Prepara tu estrategia
  1. Analiza todos los requisitos.
  2. Comprueba el estado actual del sistema.
  3. Decide qué cambios son necesarios.
  4. Identifica qué operaciones requieren privilegios administrativos.
  5. Realiza los cambios.
  6. Comprueba cada resultado.

🔍 Prove that it works

Terminar los comandos no significa haber terminado el reto. Debes demostrar que el sistema cumple los requisitos.

Debes comprobar ¿Qué debes demostrar?
👤 Usuario Que daw_temp existe.
👥 Grupos Que pertenece a los grupos requeridos.
🛡️ Administración Que puede realizar las tareas administrativas previstas.
📁 Estructura Que los directorios y archivos solicitados existen.
👤 Propiedad Que los recursos tienen el propietario y grupo adecuados.
🔐 Permisos Que los permisos coinciden con los requisitos.
⚠️ Un resultado correcto no es suficiente

Debes ser capaz de explicar qué has hecho y por qué. Si utilizas un comando, debes comprender qué modificación produce sobre el sistema.

🩺 If something goes wrong...

No reinicies el reto inmediatamente. Lee el mensaje que devuelve el sistema, comprueba tu situación actual y trata de determinar qué requisito no se está cumpliendo y por qué.
